- 초기 비밀번호: `123456`

## 이번 버전에서 추가된 기능
- 데이 오프를 π 상점에서 구매하는 쿠폰 방식
- 구매한 데이 오프 쿠폰을 미션 화면에서 직접 1회 사용
- 데일리 미션을 날짜별로 저장하고 매일 다른 미션이 자동 선택되는 구조
- 데일리 미션에 날짜 표시
- 위클리 미션을 주차별로 저장
- 데일리/위클리 미션을 캘린더에서 날짜별로 확인
- 대표가 오늘의 데일리/이번 주 위클리 미션을 직접 수정 가능
- 대표가 과목을 추가/삭제
- 대표가 판매할 상품/프리미엄 칭호를 직접 추가
- 상품 가격과 한정 수량 설정
- 수량이 0이면 품절 처리
- `-1` 수량이면 무제한 판매
- 상품 판매 종료 기능
- 수강 개설 과목 추가 및 임시 폐지/재개

## 참고
현재 파일은 화면과 기능을 확인하기 위한 프로토타입입니다. 실제 서비스로 배포하려면 서버와 데이터베이스를 연결하고, 파일 업로드/3일 후 삭제, 여러 기기에서의 동시 로그인, 실제 역할별 권한, 보안 강화 등을 서버에서 구현해야 합니다.
